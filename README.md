編集距離問題（文字列sを文字列tに変換できる手数）
各操作のルールは以下の通り

・一文字任意の位置に挿入
・任意の一文字を削除
・任意の一文字を置換

二次元dpで考えることができる

n=s.size(),m=t,size()としてn+1行m+1列行列dpを考える
dp[i][j]にはsのi文字目までをsのj文字目までに編集するときの最小手数が入るようにする

・dp[i+1][j]はdp[i][j]の状態からsのi+1文字目が追加されるのでそれを消去する操作を一回加えればよい。
・dp[i][j+1]はdp[i][j]の状態からtのj+1文字目が追加されるので、それにともなってi側もそれと同じ一文字を追加すればいい。
・dp[i+1][j+1]はdp[i][j]の状態からs側もt側も一文字追加されるので、sのi+1文字目とtのj+1文字目が同じなら操作はしなくてよい。異なるならsのi+1文字目をtのj+1文字目と同じものに置換すればよい。

これらをまとめると大まかに

if(s[i-1][j-1]==t[i-1][j-1]) dp[i][j] = min(dp[i-1][j]+1,dp[i][j-1]+1)
else dp[i][j] = min({dp[i-1][j-1]+1,dp[i-1][j]+1,dp[i][j-1]+1})

である
これらはiやjと1の大小によってさらにifで場合分けする必要がある
